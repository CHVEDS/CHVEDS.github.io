## Задача

Перед разработкой AI EdTech‑платформы нужно было проверить архитектуру диалогового контура «студент ↔ оркестратор ↔ рой агентов». Проверить так, чтобы ядро запускалось без ключей и внешних сервисов, но в точности повторяло продакшен‑стек.

## Решение

- **Оркестратор** классифицирует домен и сложность вопроса и через structured output выбирает стратегию: один эксперт, цепочка экспертов или дебаты.
- **Три ReAct‑эксперта** со своими срезами базы знаний и инструментами (песочница для кода, калькуляторы, GitHub и Kaggle API) работают в цикле «мысль → действие → наблюдение».
- **Multi‑Agent Debate** для спорных вопросов.
- **Синтез** добавляет дидактику и цитаты, **рефлексия** обновляет граф знаний студента.
- **Grounding‑first:** эксперт отвечает только по найденным источникам, отдельный тест это проверяет.

Ядро работает офлайн на детерминированном мок‑LLM, а на продакшен‑бэкенды (vLLM, LangGraph, Qdrant, Langfuse, Neo4j) переключается сменой конфигурации.

## Результат

Работающий референс второго этапа roadmap платформы: три демонстрационных сценария с трассировкой, 10 из 10 юнит‑тестов, запуск без `pip install` — только стандартная библиотека Python. Этот подход лёг в основу архитектуры Tandemind.
