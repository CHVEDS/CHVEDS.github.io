## Задача

Ведение канала с житейскими историями для аудитории 55+ требует регулярных статей в узнаваемом стиле. Нужно сократить ручную работу до вычитки: тему, текст и иллюстрацию должен готовить конвейер, а человек — только проверять и публиковать.

## Решение

Воркфлоу в n8n из 12 шагов:

1. **RSS** даёт актуальные темы — «зерно» для истории.
2. **GigaChat оценивает тему** и возвращает структурированный JSON: подходит ли она, ключевые слова, угол подачи.
3. Если тема подходит, **GigaChat пишет статью** по системному промпту со стилем канала.
4. **Unsplash** подбирает фото по ключевым словам.
5. Черновик со статусом `draft` сохраняется в **SQLite** для ручной вычитки.

GigaChat выбран потому, что работает из России. Токен доступа получается заново при каждом запуске, так что истёкший ключ не ломает конвейер.

### Пульт в Telegram

Отдельный бот на Python запускает воркфлоу через вебхук, показывает статус сервера и присылает готовую статью со ссылкой на картинку. Генерацию можно запустить с телефона, не открывая n8n.

## Результат

Полуавтоматический конвейер: от темы до готового черновика — одна кнопка, человек остаётся только редактором. Есть инструкция по установке бота на Ubuntu Server.
