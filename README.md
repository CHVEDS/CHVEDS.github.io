# Портфолио

Личный сайт-портфолио на [Astro](https://astro.build). Хостинг на GitHub Pages, сайт обновляется сам после каждого `git push`.

## Быстрый старт

Нужен [Node.js](https://nodejs.org) версии **22.23 или новее**.

```bash
npm install      # один раз: установить зависимости
npm run dev      # локальный сайт на http://localhost:4321 (обновляется при сохранении файлов)
npm run build    # проверка типов + сборка в папку dist/
npm run preview  # посмотреть собранный сайт
```

## Где что менять

Пошаговый план наполнения — в локальном файле `CONTENT.md` (в репозиторий не попадает).

| Что | Где |
|---|---|
| Имя, роль, контакты, тексты рабочего стола, терминал, TODO, навыки | `src/config/site.ts` |
| Цвета, шрифты, отступы (весь визуал) | `src/styles/tokens.css` |
| Обои рабочего стола | `src/assets/wallpaper.png` |
| Текст страницы «Обо мне» | `src/data/about.md` |
| Проекты | `src/content/projects/<slug>/index.md` |
| Мини-проекты лаборатории | `src/content/lab/<slug>/index.md` |
| Резюме для иконки на рабочем столе | `public/resume.pdf` + `contacts.resume` в `site.ts` |
| Иконка сайта и превью для соцсетей | `public/favicon.svg`, `public/og-default.png` (1200×630) |

## Как добавить проект

1. Скопируй папку `src/content/projects/_template` и назови её латиницей через дефис, например `it-digest`. Это имя станет адресом страницы: `/projects/it-digest`.
2. Заполни поля в `index.md`. Список полей и подсказки есть в самом шаблоне.
3. Положи картинки рядом с `index.md`: `cover.png` для обложки (16:10), остальные вставляй в текст как `![](./screen.png)`. Astro сам сожмёт их и переведёт в webp.
4. Пока стоит `draft: true`, проект виден только при `npm run dev`. Чтобы опубликовать, поставь `draft: false`.
5. `featured: true` выводит проект на главную, а `order` задаёт порядок там.

Если ошибиться в поле (например, указать несуществующую категорию), сборка остановится и покажет, в каком файле и какой строке ошибка. Сломанный сайт не опубликуется.

Пример для проверки вёрстки лежит в `src/content/projects/example-project` (это черновик, на сайт он не попадает). Когда появятся настоящие проекты, его можно удалить.

## Публикация на GitHub Pages

1. Создай на GitHub репозиторий **`CHVEDS.github.io`**, тогда сайт будет доступен по адресу `https://chveds.github.io`.
2. Залей в него эту папку:
   ```bash
   git init
   git add .
   git commit -m "Основа портфолио"
   git branch -M main
   git remote add origin https://github.com/CHVEDS/CHVEDS.github.io.git
   git push -u origin main
   ```
3. В репозитории открой **Settings → Pages → Source** и выбери **GitHub Actions**.
4. Готово. Каждый `git push` в `main` собирает и публикует сайт (ход сборки видно на вкладке **Actions**).

**Другое имя репозитория** (например, `portfolio`): в `.github/workflows/deploy.yml` раскомментируй `BASE_PATH: /portfolio`. Сайт будет по адресу `https://chveds.github.io/portfolio`.

**Свой домен:** создай файл `public/CNAME` с доменом внутри (например, `heres.dev`), поменяй `SITE_URL` в `deploy.yml` и настрой DNS по [инструкции GitHub](https://docs.github.com/pages/configuring-a-custom-domain-for-your-github-pages-site).

## Структура

```
src/
├── config/site.ts         ← все настройки и тексты
├── content.config.ts      ← схема полей проектов
├── content/projects/      ← проекты (одна папка = один проект)
├── content/lab/           ← мини-проекты
├── data/about.md          ← текст «Обо мне»
├── assets/wallpaper.png   ← обои
├── styles/                ← токены и базовые стили
├── components/os/         ← «операционная система»: окна, док, меню, иконки, терминал, виджеты
├── layouts/               ← каркас страницы и страница проекта
├── lib/                   ← выборка контента, статистика GitHub
└── pages/                 ← /, /projects, /lab, /about, 404
```

## Что уже есть

- Главная в виде рабочего стола: окна можно перетаскивать и закрывать, иконки открываются двойным кликом, терминал печатает строки.
- Виджет активности берёт реальную статистику с GitHub при сборке сайта. Если GitHub недоступен, виджет скрывается.
- Внутренние страницы открываются окнами: «Проводник» с фильтрами, README проекта с панелью свойств.
- На экранах уже 1100px окна выстраиваются в ленту, а док становится нижней навигацией.
- SEO: заголовки, описания, превью для соцсетей, sitemap, robots.txt.
- Оптимизация картинок и проверка полей контента при сборке.
